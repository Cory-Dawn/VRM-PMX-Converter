# 简体中文

VRM → PMX 转换器是一款免费开源的 Windows 工具，可将 UniVRM 输出的 VRM 0.x 角色模型转换为 MMD 使用的 PMX 模型。

## 本版更新

- 新增英语和日语界面，可在主窗口顶部切换，选择会自动保存。
- 改善小窗口下的按钮和模型列表显示，并完善恢复默认提示。
- 增加英文和日文的仓库说明。

## 主要特点

- 自动生成常用 MMD 骨骼及辅助骨骼，减少手动追加工作。
- 可选生成动作调整骨，自定义整体位置，方便手动打关键帧修正已有动作中的穿模。
- 根据 VRM 弹簧骨参数生成物理，针对 MMD 中的抖动进行优化。
- 自动分类表情面板，转换部分材质颜色和透明度开关。
- 复用同一贴图，继承 VRM 材质的描边和双面显示设置。
- 可选转换材质与表情名称中的部分中文以缓解乱码；支持拖放、批量添加及浅色／深色界面。

## 下载和使用

在下方 Assets 中下载 `VRM2PMX_v1.5.1_release.zip`，解压后运行 `VRM2PMX.exe`，无需安装 Python。压缩包还包含命令行工具、使用说明和许可证声明。

不同模型和动作的效果可能不同，请在 MMD 或 PMX Editor 中检查结果，并遵守模型作者的使用条款。调整骨用于手动修正，不会自动修复穿模。

# English

VRM → PMX Converter is a free, open-source Windows tool that converts VRM 0.x character models exported by UniVRM into PMX models for MMD.

## What's new

- Added English and Japanese interface languages, selectable at the top of the window and saved automatically.
- Improved buttons and the model list in smaller windows, and clarified the reset-to-defaults tooltip.
- Added English and Japanese repository documentation.

## Features

- Generates common MMD bones and auxiliary bones to reduce manual setup.
- Optionally creates repositionable motion adjustment bones for manually correcting clipping with keyframes.
- Builds physics from VRM spring-bone settings, with adjustments intended to reduce jitter in MMD.
- Organizes the morph panel and converts some material color and transparency switches.
- Reuses shared textures and inherits VRM material outline and double-sided settings.
- Optionally converts some Chinese characters in material and morph names to reduce garbled text; supports drag and drop, batch adding, and light/dark themes.

## Download and use

Download `VRM2PMX_v1.5.1_release.zip` from Assets below, extract it, and run `VRM2PMX.exe`. Python is not required. The archive also includes a command-line tool, user guide, and license notices.

Results vary by model and motion. Check the result in MMD or PMX Editor and follow the model author's terms. Adjustment bones are for manual correction and do not automatically fix clipping.

# 日本語

VRM → PMX コンバーターは、UniVRM から出力した VRM 0.x キャラクターモデルを MMD 用の PMX モデルに変換する、無料・オープンソースの Windows ツールです。

## このバージョンの更新

- 英語と日本語の画面を追加しました。メイン画面上部で切り替えられ、選択は自動保存されます。
- 小さいウィンドウでのボタンとモデル一覧の表示を改善し、初期値に戻す際の説明を明確にしました。
- リポジトリに英語版と日本語版の説明を追加しました。

## 主な特徴

- 一般的な MMD ボーンと補助ボーンを自動生成し、手動設定を減らします。
- 位置を指定できる動作調整ボーンを選択して生成し、キーフレームによるめり込みの手動修正に役立ちます。
- VRM のスプリングボーン設定から物理を生成し、MMD での揺れの乱れを抑えるよう調整します。
- 表情パネルを自動分類し、材質の色や透明度による切り替えの一部を変換します。
- 同じテクスチャを再利用し、VRM 材質のエッジと両面表示設定を引き継ぎます。
- 材質・モーフ名の中国語の一部を変換して文字化けを軽減できます。ドラッグ＆ドロップ、一括追加、ライト／ダークテーマにも対応します。

## ダウンロードと使い方

下の Assets から `VRM2PMX_v1.5.1_release.zip` をダウンロードして展開し、`VRM2PMX.exe` を実行してください。Python のインストールは不要です。ZIP にはコマンドラインツール、使用説明、ライセンス表記も含まれます。

結果はモデルやモーションによって異なります。MMD または PMX Editor で確認し、モデル作者の利用規約に従ってください。調整ボーンは手動修正用で、めり込みを自動修正するものではありません。

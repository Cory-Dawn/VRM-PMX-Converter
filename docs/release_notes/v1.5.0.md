这是 VRM → PMX 转换器的首个公开版本。软件免费开源，可将 UniVRM 输出的 VRM 0.x 角色模型转换为 MMD 可使用的 PMX 模型。

## 下载和使用

下载 `VRM2PMX_v1.5.0_release.zip`，解压后运行 `VRM2PMX.exe`，无需安装 Python。压缩包同时包含命令行工具、使用说明和第三方许可声明。

## 主要特点

- 自动生成常用 MMD 骨骼及辅助骨骼，减少手动追加工作。
- 根据 VRM 弹簧骨参数生成物理，并针对 MMD 中的抖动进行优化。
- 可选生成动作调整骨，自定义整体位置，方便对已有动作手动打关键帧修正穿模。
- 自动分类表情面板，转换部分材质颜色和透明度开关。
- 复用同一贴图，继承材质的描边和双面显示设置。
- 可选转换材质与表情名称中的部分中文，缓解乱码；支持拖放、批量添加及浅色／深色界面。

不同模型和动作的效果可能不同；转换后请在 MMD 或 PMX Editor 中检查，并遵守模型作者的使用条款。调整骨用于手动修正，不会自动修复穿模。
